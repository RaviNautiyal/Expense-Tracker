# 💰 Spendly - Expense Tracker App

A modern expense tracking application that helps users monitor their spending, manage finances efficiently, and gain insights into their financial habits through an intuitive dashboard.

🌐 **Live Demo:** https://spendly-6uv7.onrender.com/dashboard

---

## 🚀 Overview

Spendly is a personal finance management application built to simplify expense tracking and budgeting. Users can record expenses, categorize transactions, monitor spending patterns, and visualize their financial data through an easy-to-use dashboard.

The project aims to help individuals develop better financial habits and make informed spending decisions.

---

## ✨ Features

* 📊 Interactive financial dashboard
* 💸 Add and manage expenses

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/RaviNautiyal/expense-tracker.git
cd expense-tracker
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```
